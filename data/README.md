# data：公开数据来源与本地数据

> **当前路线 public-data-v1（2026-10-29）**：公开数据为主，不要求组员自行录制训练集。仓库只跟踪本说明、[`SOURCES.md`](SOURCES.md)和[`sources.json`](sources.json)；下载包、图片、关键点、原始标签与实验派生数据不进Git。

## 从这里开始

1. 查看 [公开数据下载入口](SOURCES.md)：首选IPN HandS关键点＋时间标签，主关键点包作者标称375 MB，不需要先下载视频。
2. 查看 [机器可读清单](sources.json)：官方URL、固定文档版本、许可证、预期SHA256与实际校验状态。
3. 查看 [公开数据实施方案](../docs/public_data_plan.md)：类别迁移、数据划分、模型与本机验证边界。

**当前不是“数据已准备好”**：IPN HandS标注小包的实际SHA256与作者公布值不一致，正式导入待核验；375 MB关键点大包尚未下载，训练/导入器尚未实现。清单不隐藏失败，也不以网页可访问代替文件校验。

本地已有的`InterHand2.6M.images.5.fps.v1.0.tar.partaa`及部分解压图片属于旧下载资料，不是当前主训练集。本次只读检查发现77,918张JPG位于`test/Capture1`，缺配套标注且末尾文件截断；未删除或修改这些内容。不把手姿态估计数据或多个同步相机视角当作已标注的独立手势序列。

## 本地布局

```text
data/
├── README.md                  # Git：目录与策略
├── SOURCES.md                 # Git：官方下载入口与说明
├── sources.json               # Git：版本、URL、许可、校验状态
├── external/                  # 忽略：公开数据原始下载与解压结果
├── manifests/                 # 忽略：实际下载/导入账本与文件哈希
├── landmarks/                 # 忽略：来源可追踪的关键点
├── annotations/               # 忽略：原始与版本化转换标签
├── splits/                    # 忽略：固定参与者/会话分组
├── features/                  # 忽略：可重建缓存
├── reports/                   # 忽略：本地数据完整性/质量结果
└── recordings/                # 忽略：仅用户后续自愿授权采集时生成
```

文件路径是约定，不说明这些目录已经有数据。大包由各人按官方地址下载到本地；`git pull`只同步清单和代码，不同步原始数据。公共发布地址不等于可随意重新上传数据，需要遵守各数据集实际许可及引用要求。

## 数据流与双方分工

```text
官方公开数据 → 下载/哈希/许可核验 → 时轴与类别适配
             → 质量审核 → 固定参与者/会话划分
             → shared公共特征 → algorithm自主训练 → artifacts模型与结果
```

A管理数据版本、特征和训练；B负责感知/导入适配与应用；双方复核标签映射、泄漏和演示。实际A/B人员仍待用户填写。

- 保留原始文件只读；修订映射/标签/特征生成新版本。
- 先划分后滑窗，统计只在训练集拟合，已用于开发的test资料不能继续当未见测试。
- 公共数据不包含本应用操作意图、启停/owner或应用响应真值，不伪造。
- 来源感知版本、坐标、缺手/失效、时间轴与本项目不一致时显式处理，不靠改时间或补假点掩盖。
- 不使用作者预训练手势分类器冒充自主训练；MediaPipe只承担关键点感知。

## 可选自采，而非强制前置

原计划的8人/640次正例/80分钟背景现为可选扩展参考，不是用户必须完成的任务，也不是已核实的课程硬要求。未来若自愿采集，继续遵守T06的关键点与原图分别授权、匿名化、取消/恢复规则；授权原件和身份映射放受控`private/`，不提交Git。

Git忽略不等于加密或访问控制。不要强制`git add -f`原始资料、网盘Cookie、会话HTML或个人文件。可公开的去标识汇总放`docs/`，纯合成测试样例放`tests/fixtures/`，权重及训练日志放`artifacts/`。
