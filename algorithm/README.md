## 后续模块划分

| 计划模块 | 职责 |
| --- | --- |
| `data/` | 训练 Dataset、窗口样本索引、采样、标签掩码和增强流程；只放代码 |
| `models/` | 规则/MLP、因果 TCN 及按计划开展的候选网络；只放模型定义 |
| `training/` | 损失、优化、checkpoint、恢复、实验记录 |
| `evaluation/` | 分类、事件、拒识、校准和用户级统计 |
| `inference/` | 模型包加载、统一 Predictor、校准/拒识、导出一致性 |
| `personalization/` | 原型、少样本适配、小头微调与通用模型回退 |

内部子目录和包名在实施时落地。**`algorithm/data/` 是读取数据的代码，不是数据集；`algorithm/models/` 是网络代码，不是权重仓库。**

## 第一版模型目标

先实现 MLP 与单分支因果 TCN。起点为 94 维特征、32 步窗口、4 个单卷积残差块、扩张率 1/2/4/8、感受野 31；类表从版本配置读取。

这些数值是当前计划，不是最优参数或已训练成果。多任务、拒识和少样本按任务优先级扩展，不为复杂度挤占基本实验。

## 与其他目录的关系

- 从根 `data/` 读取授权记录、标注和固定 split。
- 几何、缺失处理、时序窗口和公共记录格式直接复用 `shared/`，与在线推理保持一致。
- 训练/模型参数来自 `configs/`，权重、曲线、预测与报告写到 `artifacts/`。
- 向 `backend/` 提供符合共享契约的 Predictor；无意图/阶段头时返回缺省字段，不伪造分数。
- 不导入前端或平台操作代码；必要的完整事件评估由脚本组合后端 dry-run 引擎，再把事件交给本模块指标函数，避免算法与后端循环依赖。

## 向 B 交付的内容

1. 网络结构、类表、特征 schema 与统计量。
2. 可信来源的权重、校准参数、配置版本及哈希。
3. 固定预测接口、缺失/错误行为和一致性测试。
4. 验证结果、CPU 性能、已知限制和回退方式。

用户先划分后滑窗，统计只在训练集拟合；测试不用于阈值或 checkpoint 选择。正式训练/评估入口放 `scripts/`，不要复制两套训练实现。
