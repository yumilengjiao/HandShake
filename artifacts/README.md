# artifacts：模型、实验与运行产物

> 当前仅有本说明，没有权重、训练结果或实际运行日志。这里保存生成的产物，不存网络源码或原始数据集。

## 主责

- A 管理训练、模型、校准和算法实验产物。
- B 管理在线运行、后端、安全与性能测试产物。
- 最终发布候选、报告引用和版本关系由双方复核。

## 后续布局

```text
artifacts/
├── README.md
├── perception/            # MediaPipe 等感知模型资产、来源/许可/哈希
├── runs/                  # 每次训练的配置快照、曲线、checkpoint、RNG 状态
├── models/                # 可部署的不可变模型包
├── experiments/           # 分类、事件、消融、用户实验及原始结果
├── reports/               # 性能、安全、导出一致性和集成报告
└── logs/                  # 受控运行日志、预测摘要和事件时间轴
```

子目录尚未创建。模型定义代码属于 `algorithm/models/`，不能把本目录和代码模型目录混为一谈。

## 模型包要求

参照 [T16](../task_plans/16_export_and_online_inference.md)，包括权重、结构、类表、特征 schema、统计量、校准/事件参数、训练清单、模型卡和哈希。

- 事件参数注明 draft/frozen，frozen 包不可原位更改。
- 验证选择后生成新候选，重跑相关回归，再最终测试。
- 报告关联对应候选的哈希，不修改已测权重或配置来补结果。
- 只加载可信来源模型；记录第三方感知模型的许可，不能把仓库 LICENSE 当作其授权。
- 答辩前验证离线可获取所需资产，不依赖现场首次下载。

## 记录与发布

每次 run/experiment 使用独立 ID，记录代码、数据、split、schema、模型、配置、环境和硬件版本；失败实验也保留原因。

Git 默认只跟踪本 README，其余产物通过受控存储共享；大型权重和日志不提交普通 Git。可公开的模型卡、结果汇总和脱敏图表经审核放 `docs/`，不得冒充尚未生成的实验成果。

没有应用回执的注入日志不能称为应用已执行；没有实际注入的 dry-run 不能声称已经测得设备响应延迟。
