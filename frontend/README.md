## 职责与边界

- 视图消费只读快照，操作由ViewModel发往repository；不能在Widget内训练、做手势推断或直接执行键鼠命令。
- 显示镜像不改变模型坐标、词表或控制方向；回看不重发事件。
- 快照和时间轴有界，停止区固定，停止请求与确认分离。独立核心健康机制不能由UI重绘替代。
- T36已确定Flutter桌面路线，T20已有合成和相机预览；自训模型/应用闭环还需T16～T19/T23/T24。
- 手机T37以后通过平台相机/本地推理接同一视图边界，不依赖桌面Python服务；T38远程模式单独验收。
- Flutter子工程不纳入Python wheel；SDK、构建目录、原始数据、私有截图不入库。

## 下一阶段

1. 相机/感知已接入，有界JPEG通路、同帧对齐和短时实机重开通过；后续补长时、人工镜像/遮挡/双手和权限异常验证。
2. 模型包身份/词表、ready/拒绝原因与真实输出；仍保留未知能力禁用。
3. 人工启用、明确目标、唯一调度器、停止/释放与正常关闭；不把合成预览启停等同于live授权。
4. 模型/模式/输入切换、权限/后台与故障提示、独立安装、读屏和多平台实测。
