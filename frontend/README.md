# frontend：桌面前端与交互界面

> 当前仅有职责说明，尚未选择或安装 UI 框架，也没有可启动界面。

## 主责与任务

- **B 主责**；A 协助模型输出、指标展示与数据标注需求。
- 核心任务：[T20 基础界面](../task_plans/20_desktop_ui.md)。
- 关联 T06 采集/标注辅助、T21/T22 媒体/光标界面、T23 集成与 T27 个性化向导。

## 本目录负责什么

- 摄像头与关键点预览、镜像提示、实际帧率。
- 模型版本、预测类别、控制者、ready、状态与拒绝原因。
- 预览、启用、禁用、紧急停止以及明确可见的 dry-run/live 状态。
- 演示/音乐/光标模式选择，未实现能力禁用并说明原因。
- 最近命令的拟执行/注入/响应结果。
- 相机设置、用户校准向导、采集与标注辅助视图。

后续内部可按 `views/`、`components/`、`controllers/`、`view_models/` 划分；这些子目录尚未创建。UI 框架依目标机器、许可、刷新与打包实测选定，不默认要求 Web 技术栈。

## 输入输出与边界

- 从 `backend/` 消费只读状态快照，通过 `shared/` 定义的接口发送用户指令。
- 界面不直接调用鼠标、键盘、媒体或系统权限接口。
- 不重新实现关键点特征、模型推理和事件状态机。
- UI 控制器只做输入校验、消息转发及视图协调；整体生命周期与执行状态由后端应用控制器拥有。
- 相机/推理/写盘不能阻塞绘制。独立停止接收和安全释放属于后端，不能只靠 UI 窗口内快捷键。
- 显示镜像仅影响画面及叠加坐标，不偷偷改变模型坐标或手势标签。
