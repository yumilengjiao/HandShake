## 支持矩阵

| 平台/应用 | 能力 | 权限/停止 | 状态 |
| --- | --- | --- | --- |
| 当前 Linux / 合成 mock target | 合成 next/previous_slide | 无相机、网络或桌面权限；命令行有限执行后退出 | 软件验证结果见 [T01/T02/T05 验证记录](verification_t01_t02_t05.md) |
| 当前 Wayland / 真实幻灯片应用 | 翻页 | 焦点查询、全局停止、按键方法均待验证 | **不支持 live** |
| 未来电脑浏览器 / 应用内幻灯片 | 预览与明确目标翻页 | 授权、停止、部署方式待 T18～T24 | 计划，未实现 |
| 未来 Android/iOS 浏览器 | 手机界面、相机、触控启停 | HTTPS、设备许可、旋转/后台/断线处理待验证 | 用户要求，未实现 |
| Windows/macOS/其他宿主 | 待选择具体后端 | 待实测 | 无支持承诺 |

`configs/platforms/mock.yaml` 只描述 mock 能力，不宣告 Wayland 原生翻页或全局紧急停止已可用。前后端分区是职责边界，未来手机访问需要明确连接到哪一个宿主、哪一个目标，不能通过任意命令字符串操作电脑。

浏览器相机访问受安全上下文与用户授权约束；后续手机端实施应核对 [MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)，不能把电脑的 localhost 访问方式直接当作手机局域网方案。此处只是设计约束，没有创建服务器或证书。

真实平台验收必须补：相机型号、分辨率/帧率、显示缩放、应用版本、上一页/下一页实测方式、焦点条件、窗口在前台时独立停止证据、掉线/挂起释放与操作白名单。以上证据齐备前保持 dry-run。
