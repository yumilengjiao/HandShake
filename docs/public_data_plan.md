## 手势与首版范围调整

公开数据不必完全匹配此前自拟动作，**应使项目语义适配真实标签，而不是伪造标签**。

1. 首版采用显式UI/键盘启用和停止，保留释放、防重复、失跟、输入过期及独立停止。手势唤醒/退出不再作为公开数据版首轮必需。
2. 提议保留IPN HandS全部15个来源类别，MLP与因果TCN使用同一划分/特征；应用适配器只对经方向/含义核对的`TLT / Throw left`、`TRT / Throw right`生成上一页/下一页候选，其他类别不生成设备操作。
3. `Open twice`不能直接标成静态张掌唤醒，`Grab`不能直接标成握拳保持退出；源码词元`wake_open/exit_pose`目前仍是旧草案，不能写进假映射。
4. 来源训练词表已注册为`ipn-hands-v1`并贯穿导入/缓存/训练/分类；新`SourceClassification`不是旧`ModelPrediction`，不能直接操作设备。应用侧`gesture-public-v1`策略和按钮启停迁移仍待实施，旧`Gesture`语义和旧记录保持原版本。
5. 如果后续要恢复张掌/握拳识别，再单独评估静态数据/可解释规则。静态图片不能复制成多帧后冒充真实动态序列；规则也不能冒充训练模型输出。

课程仍做“自训模型＋基线＋真实界面＋翻页＋安全/实验”。不要求所有训练数据为自行拍摄，不要求首版手机、音乐和光标均完成。老师是否另有数据来源要求，仍以用户提供的课程原件为准，不凭原项目建议增加自采硬门槛。

## 导入必须保留的事实

- IPN HandS的帧是原视频640×480经`fps=30`提取的1-based序列，区间末端包含在内；不能使用原IPN Hand压缩帧的标签/帧编号，也不能冒充实际相机曝光时钟。
- 以每视频的帧计数与区间覆盖核对完整性；无手预测保留为空，感知未处理与模型无手结果分开，不把所有缺失当可训练背景。
- 手数组顺序不等于身份，复用完整帧关联规则生成流内track；无SDK分数就保留缺失，不伪造逐点置信度或左右手分数。
- 关键点x/y是图像归一化坐标，z是MediaPipe相对深度。GT的z未人工核验；用修正GT训练、原始检测部署会引入分布差异，应作为单独对照而非默认路径。
- 作者MPHands与本项目Hand Landmarker并非已证明相同版本/参数。记录感知血缘；可先进行公开关键点评估，若后续下载RGB再用项目SDK统一提取，单独记录结果。
- 训练/验证/测试先按参与者/会话/多视角分组后再切窗。官方test不用于试错、归一化、阈值选择；若拿它做了开发，不能继续称未见测试。
- 当前本机相机约10FPS，数据抽帧30FPS。T11/验证要覆盖采样率、间隔抖动、窗口时长与100ms草案门限，不用重复帧伪造30FPS。

## 无自录条件下能报告什么

可以报告：公开数据上的分类指标、已定义来源标签事件指标、明确预设上下文下的离线回放结果、软件故障测试，以及实际完成的本机无保存预览/交互验收。

不能凭公开数据宣称：本机任意应用全天无误触、真实操作意图识别、跨设备泛化、特定电脑上的相机到应用响应时延，或通过了未实际执行的用户研究。作者的Non-gesture不是本应用“禁用/已唤醒/有控制权”的真值；回放上下文必须标为预设。不愿录制并不妨碍无保存地做最终本机演示，若也不做则如实保留未验收。

**不再要求用户为解除数据阻塞而自行录制；但不把公开数据的证据范围夸大为真实桌面安全效果。**
