## 最小应用对接

```bash
uv run --extra training --extra perception --extra demo handshake-demo \
  --run artifacts/delivery/linux-calibrated-2026-11-03 --allow-local-demo
```

窗口内`C → E → O`依次开相机、启用、选择中立控制手；预热/释放后尝试TLT/TRT。空格停止控制，Esc关闭相机退出。可用`--slides DIR`载入PPT导出的编号PNG/JPEG。详见[操作及限制](local_gesture_demo.md)。**不注入系统按键、不控制外部PPT进程；真实识别和误触率仍未验收。**
