# 深度学习主线与答辩实验设计

> 这是实验方案与已有可运行软件的对应，不是实验结果。正式数据尚未核验完成，不填造Macro-F1、误触率或延迟。

## 项目的学习问题

MediaPipe只负责把图像变成关键点；项目自主实现/训练的是**连续手势时序分类网络**。公开数据版保留15个来源类别，模型输出原始logits；应用是否执行还要经过显式启用、时效、释放和独立停止。几何安全规则不能替代神经网络，也不能把作者预训练分类器当我们的训练结果。

```text
21×3关键点 + 质量/缺失 + 来源时间
    → 94维共享特征
    → train-only字段归一化
    → [32,94]因果窗口
    → 自训MLP / 因果TCN
    → 15类logits
    → 后续验证集校准与明确应用策略
    → 受控翻页（尚未完成公开类别联调）
```

特征为local63＋global10＋mask21：局部点位去平移/尺度，保留掌心/速度/尺度/时间/质量，避免只有归一化手型却丢失挥动方向。缺失不靠补出完美手掩盖，时间用真实来源间隔，不用相机请求帧率。

## 为什么主模型是深度时序网络

- MLP：94→128→64→C，只取窗口末步，是容量可控的基线。注意末步特征包含因果速度，因此不能宣称它完全没有历史信息。
- TCN：94→64投影，四个单卷积残差块，kernel=3，dilation=1/2/4/8；同一时刻通道归一化，不使用未来帧。每步表示依赖过去多尺度上下文，不是用if/else判断左右。
- 感受野 `1 + (3-1)×(1+2+4+8) = 31`；输入窗口32步。15类配置下MLP参数21,391，TCN参数56,975。类别数变化来自版本化词表，不只改最后一层后忽略数据/缓存/指标。
- 训练：掩码交叉熵、AdamW、梯度裁剪、验证Macro-F1早停、best/last、日志与完整epoch断点恢复；类频次和混淆矩阵跟随C，不能继续只统计前5类。
- 因果性、未来输入扰动、有限梯度和恢复一致性有自动测试。测试通过证明实现性质，不等于泛化效果。

这几个点可在答辩中展示代码、网络图、梯度/损失曲线及可复现实验，不需要堆“Transformer/大模型”等未验证名词。

## 固定数据与公平比较

1. 先完成来源SHA、时间轴、主体/会话分组核验。官方视频列表不是自动的跨主体证明。
2. 同一预登记train/val/test、来源版本、监督掩码、端点集合、特征与归一化用于MLP和TCN；test不参与统计、模型选择或阈值调整。
3. 公布初始无手、多手目标不确定、质量无效、ready不足的覆盖率和排除原因，不能只报告容易的已识别片段。
4. 每种正式模型建议至少3个预登记种子，预算明确。一次试跑通过后再跑完整预算，不默认一上来启动全部重实验。
5. 当前本机约10FPS、公开关键点30FPS，需单独验证采样率/间隔抖动与窗口时长；32步不等于固定1秒。作者MPHands与本机Hand Landmarker来源不同，域差异必须进入讨论。

## 计划实验表（结果目前为空）

| 对照 | 检验的问题 | 控制条件 |
| --- | --- | --- |
| MLP vs causal TCN | 更长时序上下文是否有实际收益 | 相同数据/特征/事件处理与预算 |
| TCN局部特征 vs 完整特征 | 全局运动/时间是否帮助区分动态动作 | 训练侧定义新特征配置，重训，不在测试时偷偷改输入 |
| 完整监督 vs 缺失/抖动压力 | 遮挡与采样变化下的可用性 | 冻结模型后按预登记扰动规则评估 |
| 正常标签 vs train标签打乱 | 数据/训练流程是否真正利用标签 | 仅用于健康诊断，不作为正式识别成绩 |
| 分类正确 vs 最终事件正确 | 是否回程重复触发/过期执行 | 同一冻结模型与明确回放上下文，分层统计 |

每类Precision/Recall/F1、Macro-F1、混淆矩阵、support、ready覆盖率必须同时报告。后续事件评估报告重复/漏发/误发与实际测试时长；源分类、拟派发、已注入、应用确认不是同一个指标。

## 答辩可展示的证据链

- **数据来源**：链接、许可、帧编号规则、真实校验失败示例，说明不是随意拼凑图片。
- **预处理**：一个来源窗口的关键点→94维→归一化→缺失掩码，全部与在线复用。
- **网络**：TCN残差块与膨胀卷积的31步因果感受野，比较末帧MLP。
- **训练**：实际日志/权重哈希、best选择规则、恢复前后参数一致性，正式结果只能来自真实运行。
- **交互**：未来界面中显示“观测→网络分数→拒绝/候选→应用回执”，不把动画当推理结果。
- **边界**：公开数据没有本机操作意图真值，不能宣传“准确读取人的意图”或未测的跨平台安全性。
