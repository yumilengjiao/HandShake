# HandShake · AI 答辩演示

## 直接打开

- **可编辑 PPT**：[HandShake_AI答辩.pptx](HandShake_AI答辩.pptx)
- **PDF 备份**：[HandShake_AI答辩.pdf](HandShake_AI答辩.pdf)
- **全部页面预览**：[预览总览.png](预览总览.png)
- **逐页讲稿与追问准备**：[讲稿与备查.md](讲稿与备查.md)

16:9 宽屏；**13 页正文 + 3 页备查附录**。正文建议讲述约 8 分钟，附录不计入正常讲述。PPT 的每一页都已写入演讲者备注，可使用 PowerPoint / WPS 的演讲者视图查看。

## 内容与版式

以人工智能内容为主，不展开 Flutter、IPC、操作系统适配等工程技术：

1. 动态手势为什么需要时序学习。
2. 公开数据、采集组隔离与类别不平衡。
3. 94 维特征与 32 帧窗口。
4. 当前 15 类因果 TCN、残差块与 **56,975** 个参数。
5. 因果性、扩张卷积与 31 帧感受野。
6. 交叉熵、AdamW、早停及验证集模型选择。
7. 真实 12 轮训练曲线、总体指标、逐类 F1 与混淆矩阵。
8. 温度校准、拒识与覆盖率代价。
9. 下一步实验及结论。
10. 附录：MLP 对照设计、完整逐类指标、证据与引用。

视觉采用暖白底、墨色文字、克制的蓝色强调及少量铜色错误标记。图表为主要叙事材料；不使用装饰性卡片墙、渐变背景或阴影堆叠。

## 可以编辑什么

- **标题、正文、数值、表格、网络结构图、箭头、特征比例条和校准比例条均为 PPT 原生元素**，可直接编辑。
- Matplotlib 图表及骨架示意以高清 PNG 插入；[assets/](assets/) 同时提供 PNG / SVG，可单独替换。**这些不是 PowerPoint 原生数据图表**。
- 生成和检查脚本仅放在本机被 Git 忽略的 `artifacts/presentation-tools/`，未加入项目运行依赖，也没有修改模型或应用代码。

## 上台前需要做的事

1. 填写封面两位汇报人的真实姓名；按实际贡献分配讲述。姓名/学号等私人版本建议另存到 `private/course/`。
2. 练习正文第 1～13 页；第 13 页结束，不默认继续讲附录。
3. 字体为 **Noto Sans CJK SC / Noto Serif CJK SC（思源黑体/宋体对应的 Noto CJK 字体）**。PPT 未嵌入字体，换机编辑或播放前请安装对应字体，并检查替换后的换行。PDF 已嵌入字体，可作为可靠的播放备份。
4. 修改 PPT 后，需要自己重新导出 PDF；已有 PDF 和预览图不会自动同步。

## 结果口径

- 图表基于 `docs/report/results.json` 与真实 `epochs.jsonl` 重绘。源日志哈希已核对，12 轮曲线逐轮匹配，并从混淆计数重新计算了总体与逐类指标。
- 主模型：当前 15 类 TCN，选定第 2 轮 checkpoint。第 6 轮原始 Macro-F1 仅提高约 `0.000042`，小于 `min_delta=0.0001`，因此没有替换。
- 验证 Accuracy **78.85%**、Macro-F1 **46.52%**；都是全量有标签窗口端点指标，不是现场动作成功率。
- 温度 `T=1.5`、阈值 `0.6` 后，覆盖率 **73.14%**；接受样本准确率 **90.23%**，全部标签正确率 **65.99%**。三种分母不能混用。
- 分组单位是来源采集组，人员身份未独立核实；不能宣称已认证的跨人评估。
- 骨架、时间序列、感受野图均为标注清楚的**结构示意图**，不冒充真实相机样本。
- MLP 正式对照、冻结后的最终测试、真实相机成功率/误触/端到端延迟仍未完成；没有为演示填造数字。
- 本次制作没有新训练网络、打开相机或读取最终测试集样本。

### 本机重新生成

制作工具是独立环境，不复用或改动项目 `.venv`：

```bash
artifacts/presentation-tools/.venv/bin/python artifacts/presentation-tools/charts.py
artifacts/presentation-tools/.venv/bin/python artifacts/presentation-tools/build_deck.py
```

以上生成 PPT、图表和讲稿；实际 PDF 转换与预览检查由本机临时 LibreOffice 及 `check_render.py` 完成。换机不要求携带这些临时工具，直接使用交付的 PPT / PDF 即可。
