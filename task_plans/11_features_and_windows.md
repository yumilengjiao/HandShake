## 目标与首版输入约定

离线训练和在线推理必须调用同一个因果特征实现。以下 94 维是对总方案的首版具体化，不是已验证最佳特征；新增/删减维度需要升 schema 并重训。输入只用图像关键点，world 坐标保留但不混入首版。纯几何/缓存实现可在 T02 契约后用合成或 pilot 数据并行开发；T10 是拟合正式统计与导出正式数据集的硬前置，不是开始写代码的前置。

## 特征维度与公式

图像宽高为 W/H，模型输入不镜像。对原始点构造 `q_i=(x_i, y_i·H/W, z_i)`，将平面坐标统一到图像宽度单位；z 仅保留 API 相对深度含义。`s=mean(||q_j.xy-q_0.xy||), j∈{5,9,17}`，掌心 `c=mean(q_j.xy), j∈{0,5,9,13,17}`。关键掌点缺失或 s 太小则判无效，不能除以极小数放大噪声。

| 片段 | 维度 | 固定顺序 |
| --- | --- | --- |
| local | 63 | 点 0～20，各点 `(q_i-q_0)/max(s,epsilon)` 的 xyz |
| global | 10 | cx、cy、vx、vy、s、ds_dt、dt_seconds、missing_ms、q_geom、motion_valid |
| mask | 21 | 各点的派生有效性 0/1，不是定位置信度 |
| 拼接 | 94 | local → global → mask |

`v=(c_t-c_prev)/dt`、`ds_dt=(s_t-s_prev)/dt`，仅同轨迹、连续有效且 dt 合理时计算；否则导数填 0、motion_valid=0。dt 用源观测差，缺失时长单独记录。当前观测有效时 missing_ms=0，无效时为当前源时间距最近有效观测的毫秒数；尚无有效历史时保留 history_initialized=false 状态并禁用执行，不用无穷值填入网络。首版不统一左右手、也不作旋转归一化，避免误改挥动方向；保留对应元数据供后续消融。

## 实施步骤

1. 固定公式、epsilon、质量起点和特征顺序写入 `feature_schema.json`，使用合成几何验证平移/尺度归一化、宽高比及方向保留。
2. 第一版不重采样到伪 30 Hz：按已处理观测构建历史，dt 保留真实间隔。成功感知但无手/质量失效可对已有轨迹追加缺失记录；未处理帧只推进健康时钟，不伪造一次无手预测，也不凭空创建背景手轨迹。长断流、换 stream/track 清历史；gap 阈值及允许的窗口时间跨度写配置，用不同采样率/抖动间隔验证，不能仅凭输入 dt 声称已解决帧率变化。
3. 仅对 local63 和 global 前 6 维（cx/cy/vx/vy/s/ds_dt）从训练集拟合统计量：坐标/尺度用有效观测，导数还要求 motion_valid；单维无样本或近零方差使用明确回退并告警。dt_seconds、missing_ms 按固定正时间尺度和截断范围变换，不按“有效手帧”拟合，否则 missing_ms 永远为 0。q_geom、motion_valid、mask 不标准化。无效几何在标准化后填 0，缺失时长/时间和质量标识保留；每字段规则写 schema。
4. 每条 recording/track 独立构造 `[T=32,D=94]` 窗口，不能跨用户、轨迹或录制拼接。标签为末端时刻的 class_id/class_valid，后续多任务同样取末端标签。训练可步长采样，验证分类按固定末端集合，事件评估回放整条流。
5. 明确定义 ready：冷启动/长失跟重置后需连续 32 个有效观测完成预热，预热中无效或超允许采样间隔则重新计数；禁止跨多段短轨迹累计到 32。预热完成后的短缺失可保留窗口，但当前失效时禁执行；恢复时还须检查窗口有效比例、最大时间跨度和当前新鲜度。相关阈值只用开发/验证选择。ready 只表示输入可用，不自动恢复 owner 或动作候选；预览允许左侧填零。分类集合预先固定并另报 ready 覆盖率，事件真值不得因启动未就绪而删除。
6. 增强仅作用训练数据，噪声/掉帧/速度扰动以不改变标签为前提；对原始观测和时间轴做变换后重算局部、全局、mask、导数，不能直接改标准化张量某几列造成不一致。水平翻转同步交换左右词元、速度与方向；时间伸缩同步变换区间/参考时刻并限制静态保持语义，首版先禁用时间反转和未经验证的速度增强。
7. Dataset 返回 x、y、loss_masks、source IDs、末端时间；训练监督可屏蔽不确定片段，但事件评估仍保留这些时段及感知失败。

## 原生移植交接

Python 训练/桌面在线保持同一实现。T37 若需非 Python 核心，优先绑定公共实现；确需移植时以版本化公式/schema 和 golden fixtures 为唯一语义基线，不允许各端复制后各自调参。交付原始观测→特征→窗口→ready/重置的逐步期望值及误差容限，覆盖旋转/宽高比、浮点精度、缺失、抖动帧率、超时与换轨迹；不能只比较最终分类标签。不同运行时不支持的数值/时间编码需在边界显式处理。
