## 目标与首版输入约定

离线训练和在线推理必须调用同一个因果特征实现。以下 94 维是对总方案的首版具体化，不是已验证最佳特征；新增/删减维度需要升 schema 并重训。输入只用图像关键点，world 坐标保留但不混入首版。

## 特征维度与公式

图像宽高为 W/H，模型输入不镜像。对原始点构造 `q_i=(x_i, y_i·H/W, z_i)`，将平面坐标统一到图像宽度单位；z 仅保留 API 相对深度含义。`s=mean(||q_j.xy-q_0.xy||), j∈{5,9,17}`，掌心 `c=mean(q_j.xy), j∈{0,5,9,13,17}`。关键掌点缺失或 s 太小则判无效，不能除以极小数放大噪声。

| 片段 | 维度 | 固定顺序 |
| --- | --- | --- |
| local | 63 | 点 0～20，各点 `(q_i-q_0)/max(s,epsilon)` 的 xyz |
| global | 10 | cx、cy、vx、vy、s、ds_dt、dt_seconds、missing_ms、q_geom、motion_valid |
| mask | 21 | 各点的派生有效性 0/1，不是定位置信度 |
| 拼接 | 94 | local → global → mask |

`v=(c_t-c_prev)/dt`、`ds_dt=(s_t-s_prev)/dt`，仅同轨迹、连续有效且 dt 合理时计算；否则导数填 0、motion_valid=0。dt 用源观测差，缺失时长单独记录。当前观测有效时 missing_ms=0，无效时为当前源时间距最近有效观测的毫秒数；尚无有效历史时保留 history_initialized=false 状态并禁用执行，不用无穷值填入网络。首版不统一左右手、也不作旋转归一化，避免误改挥动方向；保留对应元数据供后续消融。

## 实施步骤

1. 固定公式、epsilon、质量起点和特征顺序写入 `feature_schema.json`，使用合成几何验证平移/尺度归一化、宽高比及方向保留。
2. 第一版不重采样到伪 30 Hz：按实际观测时间形成历史，非均匀间隔由 dt 输入；无手/失效帧可形成带零几何及零 mask 的缺失记录，不能用未来帧插值。长断流/换 track 清空历史。
3. 对 63 维 local 和前 8 维连续 global，仅用 train 有效元素拟合均值/标准差；q_geom、motion_valid、mask 不标准化。缺失几何在标准化之后填 0，缺失标识保留；排除缺失/导数无效值拟合相应统计量。
4. 每条 recording/track 独立构造 `[T=32,D=94]` 窗口，不能跨用户、轨迹或录制拼接。标签为末端时刻的 class_id/class_valid，后续多任务同样取末端标签。训练可步长采样，验证分类按固定末端集合，事件评估回放整条流。
5. 冷启动与长失跟重置后，仅在累计 32 个有效观测步后允许普通事件；填零窗口仅供预测预览。短缺失保持 mask 与时间特征，禁止在该失效时刻执行；上线门控逻辑和离线回放一致。
6. 增强仅作用训练数据，噪声/掉帧/速度扰动以不改变标签为前提；水平翻转必须交换左右词元、速度符号和全局方向。首版先禁用时间反转和无标签变换。
7. Dataset 返回 x、y、loss_masks、source IDs、末端时间；训练监督可屏蔽不确定片段，但事件评估仍保留这些时段及感知失败。

- [ ] 缺失、重复时间、长间隔、镜像、尺度过小、轨迹切换都有合成测试。
