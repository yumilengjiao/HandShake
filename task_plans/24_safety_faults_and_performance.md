## 目标与测试清单

验证系统在出错时停止执行，以及在目标 CPU 上真实可用。各项先预定条件、重复次数和通过标准，不能只录一次顺利演示。

| 场景 | 必查行为 |
| --- | --- |
| 空画面/部分手/遮挡/两手交叉 | 不授予错误控制权，停止新命令并安全释放 |
| 重复/乱序/过期预测 | 不补发旧事件、不跳回过去位置 |
| 停止和普通命令同轮 | 停止优先，队列撤销，旧 epoch 命令拒绝 |
| 推理 sleep/死锁模拟 | 独立停止仍响应；健康监控不依赖新预测 |
| 摄像头占用/断连/重连 | 明确故障，重连只预览，不自动 live |
| 损坏模型/NaN/错误 schema | 拒绝加载或停止预测驱动，不沿用旧命令 |
| 焦点切换/权限不足/后端异常 | 不误投递、不无界重试，区分 uncertain；注入副作用后才报错、stop 后晚到完成也要测 |
| 配置/模式/模型切换与 UI close | 清候选、清队列、释放、重置历史 |
| 日志磁盘失败/重复 stop | 不阻挡释放；反复 stop 幂等 |
| 拖拽过程失效（启用该能力时） | 首次明确失效即释放，不等待分类 release |

## 原生平台增量场景

首桌面先验，新增平台由 T37/T38 复用本清单并独立出报告；不将移动或远程完成反设为本任务 P0 启动前置。

| 场景 | 必查行为 |
| --- | --- |
| 桌面锁屏/休眠、会话断开、权限撤销 | 独立挂起与释放；恢复只预览，旧工作不执行 |
| 手机后台/锁屏、来电或相机中断、进程重建 | 默认停用；不假设后台相机、退出回调或 finally 必达 |
| 手机横竖屏、前后相机切换 | 方向与元数据正确；换流/epoch 清历史、重新预热与授权 |
| 移动热降频/低电量/内存压力 | 记录有效 Hz/延迟/温升，队列有界，不能靠放宽 TTL 执行旧动作 |
| 非 Python 运行时/模型转换 | 对照 golden 特征/窗口/logits/事件/停止；不能只测分类标签 |
| T38 配对撤销/断连/延迟/重放 | 目标端 watchdog 停止并释放；过期/旧会话拒绝，不补发/自动重试 |

外部控制缺可靠停止/释放证据时禁用相应能力，手机应用内能力仍可单独验收。各 OS/ABI/机型报告分开，不将模拟器/构建成功当实机结果。跨设备延迟只在已定义时钟映射及误差界限下统计，不直接相减两个 monotonic 时间。

## 计时与负载方案

1. 保存源帧时间、关键点结束、特征结束、推理结束、事件提交、系统注入和可选应用响应；p50/p95 直接测各段及端到端，不能把各段 p95 简单相加。
2. 分开报告稳态“新鲜帧→注入”、参考确认→注入、动作开始→注入、冷启动/唤醒耗时。32 帧历史约一秒不是每个稳态事件都额外一秒。
3. 记录机器、OS、应用、分辨率、实际 Hz、手数、线程、模型/配置哈希、队列峰值和丢帧。人工施压验证最新帧策略，超 TTL 拒绝，不靠放松门限赶 FPS。
4. 独立停止延迟分别测信号接收→禁止新提交、→安全释放确认；在演示前台、UI 卡顿、推理阻塞、后端阻塞下分别测。≤200ms 是设计目标，不达标如实报告；无遗留状态和无停止确认后旧提交是安全门槛，不因性能数字为目标就可豁免。测试“按下实际发生但回执超时”和晚到完成，无法安全释放则禁用相关 live 能力。
5. 做约 30～60 分钟稳定性，采样 RSS、线程存活、日志轮转、相机重连与多次 stop；开发压力/自然活动测试用于修复，但最终留出误触评估在 T28 配置冻结后进行。稳定性不替代误触证据；故障资料如已用于调参不能再称未见测试。
6. 强杀进程、电源断开等进程内清理无法保证的边界单独实测/披露；不能把正常 finally 清理推广为任何故障都零风险。
