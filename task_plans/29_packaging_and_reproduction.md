## 目标

让另一名组员或评审按 README 在明确支持的平台安装、加载正确模型、运行 dry-run、查看评估，再受控启用已验证应用。安装/启动脚本、模型获取和离线运行冒烟应从 T02/T16 开始维护，不等所有实验结束才发现环境不可用；T24/T28 是最终发布签认前置。项目源码授权、数据授权和权重许可分别说明。

## 实施步骤

1. 冻结 release manifest：代码 revision、依赖锁、平台/应用/权限、特征/模型/数据/配置版本、所有公开文件哈希。保留已验证旧模型包与回退方法。
2. 统一 CLI/脚本，不必同时维护两套业务实现。最终 README 列出实际已存在的安装、collect、validate_dataset、build_splits、build_features、train、evaluate、export_model、replay、dry_run/live 和 benchmark 命令；本任务文档不预先声称这些命令已经能跑。
3. 用干净环境或第二台已声明支持的机器按说明完整试运行。无 GPU 时默认 CPU，无相机时可运行合成/获授权回放；不依赖开发者私有绝对路径。
4. 提供小型授权样例或纯合成 fixture，仅用于验证格式/流程，明确它不能替代真实实验数据。若不公开主数据，写清获取条件及无法完全复现的部分。
5. 模型卡从实际 architecture/schema 读取维度、窗口、类别、分支/头（课程起点为 94/32，扩展不可继续硬写旧值），说明数据/划分、预算、验证、实测指标、平台与边界。权重、预处理、校准和事件配置均以 T28 实测的不可变哈希发布，结果报告外部关联，禁止为填报告原位修改已测包。
6. 复核发布目录不含原视频、实名课程附件、身份映射、授权原件、凭据、个人档案和未经允许数据。感知 `.task` 模型与自训练权重均注明来源/许可/哈希；答辩前验证离线启动，不依赖首次联网下载。明确删除范围：原始/派生数据、个人适配器、备份及已发布副本分别处理；通用模型若受删除请求影响需评估重训，不能承诺删除源文件即从权重中遗忘。
7. 启动默认 dry-run；README 解释 live 所需目标/能力/权限和停止方式。安装包只有实测构建/启动通过才提供，不把 zip 源码称为跨平台可安装应用。
