## 目标与进入条件

## 输入和具体网络草案

沿用 T11 的 94 维有序特征：local63、global10、mask21。

| 模块 | 明确结构与维度 |
| --- | --- |
| 局部分支输入 | local63+mask21=84；逐帧 Linear(84,64)→ReLU→Linear(64,96)→ReLU |
| 全局分支输入 | global10；逐帧 Linear(10,32)→ReLU→Linear(32,64)→ReLU |
| 时序编码 | 两分支各用 T13 的单卷积残差块，通道各 96/64，扩张 1/2/4/8，各感受野31 |
| 融合 | 末帧拼接 160→Linear(160,128)→ReLU→Dropout(0.2) |
| 类别头 | Linear(128,C)→logits；C 取实际词表 |
| 意图头 | Linear(128,1)→logit，训练用 BCEWithLogitsLoss |
| 阶段头 | Linear(128,4)，background/preparing/active/releasing |
| 可选嵌入 | Linear(128,64) 后 L2 归一化；有 T27 实验需求才加入 |

LayerNorm 仍只沿单时刻通道，不能通过归一化引入未来。输入窗口、因果边界、冷启动与特征版本沿用主链路。

## 训练和监督

`L=λ_cls·CE_valid + λ_int·BCE_valid + λ_phase·CE_valid`。首轮 λ 可全为1，每项按本任务有效标签数求均值；全无监督的头跳过，不能把缺标签算负类。研究嵌入需另加明确度量损失或原型目标，不把随意投影当作已学到可用距离。

自然挥手与指令挥手可以同类别、不同 intent。阶段是动作进程而非授权，完成阶段也不自动获得控制权。意图头是否真正学到交互线索必须按用户/环境控制，不让屏幕提示、固定时间或采集位置泄漏答案。

## 逐项对照与接入

1. 单分支 TCN → 双分支单任务，比较 local/global 解耦；尽量匹配容量并记录参数与预算差异。
2. 双分支类头 → 加意图头 → 再加阶段头；不要一次增加全部模块后无法归因。
3. 使用相同事件协议；加入意图门限/阶段判据时另做后处理消融，避免模型和状态机同时改变掩盖收益来源。
4. 在验证集调损失权重、checkpoint 和门限，冻结后才评估测试；检查 phase 总预测 background、intent 只预测有手等退化。
5. 新模型包声明 heads、标签版本和阈值。无头的旧模型保持可回退，新增逻辑由配置显式启用。

## 交付与验收

双分支模型、heads/loss 代码、训练配置、消融表、参数/耗时报告及在线回放。

- [ ] 分支与头维度正确，掩码不会产生 NaN；每头有可靠监督来源。
- [ ] 未来扰动不改变过去输出，导出一致性通过。
- [ ] 在可比召回下报告误触、重复和响应时间，不只报分类准确率。
- [ ] 复杂模型无稳定收益时保留简单版，负结果进入 T28。
