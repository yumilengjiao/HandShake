## 目标

在数据和计算资源允许时比较注意力时序模型，不把 Transformer 设为课程必需。仍使用94维/32帧、同一 split 与末端标签，确保只改变时序编码。

## 首轮结构和步骤

1. 输入逐帧投影94→64，加入明确的时间表示（样本位置与实际 dt 的选用写配置）；使用2层轻量编码块、4头注意力、每头16维、FFN宽128、dropout0.1，末端 token 接64→C类别头。
2. 注意力显式使用只看当前及过去的因果 mask，核对所用 API 布尔 mask 的允许/屏蔽语义；不同接口可能相反，必须以小张量和未来扰动测试确认。归一化只沿通道。
3. 缺失观测用独立 mask/质量特征；不是把每个缺失 token 都无条件当 padding。避免一行全被屏蔽导致 NaN；无有效历史时只预览、不执行。
4. 位置编码在滑动窗口中保持训练与部署口径，首版每次重算窗口，不默认加入 KV 缓存。若后续缓存，写清位置移动/截断/重置规则并验证等价性。
5. 使用 T14 相同选择指标和可比搜索预算，报告实际参数、推理、内存与采样率变化，不只看最高 Macro-F1。
6. 未来扰动、短前缀、缺失、导出和 end-to-end 事件回放都通过后，才评估作为替代模型；不能用双向离线注意力结果声称实时性能。

## 输出与验收

候选模型、因果/缺失测试、配置、对照和部署报告。

- [ ] 过去输出不受未来变化影响，缺失输入没有 NaN。
- [ ] 同样事件门控下报告分类、误触、召回和延迟；是否达到实时由目标机器实测。
- [ ] 小数据无稳定收益时保留 TCN，不扩大网络以追求单次最好结果。
