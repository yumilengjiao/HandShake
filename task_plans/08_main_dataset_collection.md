## 当前路线

以官方公开手势数据为主，不要求组员自行录制。下载入口、许可、固定版本和核验状态集中在 [data/SOURCES.md](../data/SOURCES.md) / [data/sources.json](../data/sources.json)，执行边界见 [公开数据方案](../docs/public_data_plan.md)。数据仍是核心工作，但“自主训练”不要求“所有图片由自己拍摄”。

## 实施步骤

1. T07先冻结可用来源。优先关键点＋匹配的时间标签，不默认下载GT/Holistic/全部RGB；IPN HandS的MPHands主包作者标称375 MB，当前尚未下载。
2. 下载到Git忽略的`data/external/<dataset>/`，记录官方来源/文件名/版本、实际字节数与哈希、时间、许可/引用、下载是否完整。分享页HTTP200不等于文件下载或校验通过。
3. 对有官方SHA的文件严格核对；不匹配拒绝正式导入，不覆盖已有资料、不把观测值替换成“预期值”。检查归档成员、CRC和安全路径后再按受控导入流程使用，不自动执行包内脚本。
4. 文件/帧/区间数量、来源类别、训练/测试名单建立不可变账本。保留原始版与HandS版不同时间轴，派生结果记录来源哈希与转换版本。
5. 记录参与者/会话/视角的分组依据。官方split只作为起点，检查泄漏；先从训练侧预登记验证用户，不根据最终测试成绩挑用户。缺可靠主体信息时报告划分局限。
6. 保留连续序列和非手势，不只导出最容易的动作片段。缺手、感知失败、无效/损坏、实际类别未知分别处理；记录排除规则与数量，不只保留识别成功帧。
7. 如需项目SDK统一提取，再按可用来源下载原始RGB并明确匹配的时间轴/标签；原始IPN Hand视频作者标称4.6 GB，非首轮默认下载。HaGRID大包不是首版前置。

## 交付与验收

- 本地`data/manifests/`包含实际来源文件、哈希、许可证/引用、类别/时轴/主体分组账本；公开Git只提交经审查的URL和摘要。
- [ ] 所有实际使用的下载包完整、哈希核对通过或无官方哈希时明确来源和本地校验边界。
- [ ] 来源标签/时间轴/参与者可追踪，正式版本不可静默覆盖。
- [ ] 正例、非手势、缺手、失效和损坏数量可重算，所有排除有理由。
- [ ] 原始内容不进Git；T09标签审核和T10划分使用冻结版本。

## 可选自采参考，不是当前门槛

旧计划的8人×4词元×每类10次×2会话（约640次正例尝试）及每人每会话5分钟自然活动（共80分钟），仅在未来自愿扩展时参考。真实授权、匿名化、背景覆盖、失败记录与4/2/2分组仍需按实际执行；不能将建议规模当老师已确认的硬要求，也不能复制样本凑人数。研究版24人规模更不是课程前置。

不自行录制时，不声称公共数据包含本机启停/owner/操作意图或应用响应真值；独立本机无保存演示与公开数据评估分开报告。
